# Power BI report-definition source (PBIR)

This directory contains the actual five-page cleaned `.Report` report-definition export that was used to build the project layout. It has **81 native visuals** distributed across five pages and includes the original page JSON, visual JSON, and report theme resources.

It is **not** a fully functional, standalone Power BI project. The semantic model and top-level `.pbip` are absent from the supplied report-only export. See [reproduction.md](../docs/reproduction.md) for safe installation in an existing compatible PBIP project, or use the full linked PBIX download.
