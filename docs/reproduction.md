## Report source shipped here

`powerbi/ubers latest september 2.Report/` contains the five-page cleaned PBIR definition. **It is not a full self-contained Power BI project.** The report file `definition.pbir` points to a sibling folder named `ubers latest september 2.SemanticModel`, which is deliberately absent because the supplied ZIP contained only the `.Report` folder.

### Advanced use with a compatible existing PBIP

1. Close Power BI Desktop and **back up the entire existing PBIP project**.
2. Ensure your existing project has `ubers latest september 2.SemanticModel` and its top-level `.pbip` alongside the existing `ubers latest september 2.Report` folder.
3. Replace the entire `ubers latest september 2.Report` folder with the report folder copied from this repository. Do not merge an old generation of visuals into the new page definitions.
4. Open the existing `.pbip` project and validate every chart against the original model.
5. Confirm `_Measures[Rides With Negative Duration]` exists; its documented DAX is in `docs/dax-measures.md`. The owner resolved that missing-model-measure binding inside Desktop.

**Never assume** a report-only source folder can open and refresh independently. It cannot replace the missing model, data connections, or `.pbip` launcher.

## Reproducing data preparation from TLC

The original source is TLC FHVHV Parquet for 2024-01 and 2024-02 plus taxi-zone lookup; see <https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page>. The original Power Query connection used a Windows-local folder. To refresh on another machine, download the same source files and reconfigure the query parameters/folder location in Desktop.

The full original transformation source (Power Query M/TMDL) was not part of the uploaded report-only ZIP, so the README and measure catalog document known design choices but are not a turn-key replacement for the PBIX.
